# 抖音逆向 IPC 接口说明

- 协议：HTTP JSON
- 默认地址：`http://127.0.0.1:8765`
- 在线调试页（服务启动后）：`http://127.0.0.1:8765/docs`
- 启动命令见同目录 `README.md`

## 统一响应格式

成功：

```json
{
  "ok": true,
  "data": {}
}
```

失败（HTTP 状态码一般为 400）：

```json
{
  "ok": false,
  "error": {
    "code": "peer_required",
    "message": "conversation_id or peer_uid is required"
  }
}
```

## 1. 探活与基础

### 1.1 探活

- **GET** `/ping`
- **说明**：服务是否可用
- **成功 data 示例**：

```json
{ "pong": true }
```

### 1.2 当前数据库路径

- **GET** `/db_path`
- **说明**：返回服务使用的 SQLite 路径
- **成功 data 示例**：

```json
{ "db_path": "D:\\...\\_douyin_im_accounts.db" }
```

---

## 2. 账号

路径中的 `{account_code}` 为账号唯一标识，必填。

### 2.1 账号列表

- **GET** `/accounts`
- **成功 data 示例**：

```json
{
  "accounts": [
    {
      "account_code": "my_test_acc",
      "running": false,
      "connected": false,
      "last_error": "",
      "last_msg_at": "",
      "enabled": true
    }
  ]
}
```

### 2.2 账号状态

- **GET** `/accounts/{account_code}/status`

### 2.3 开始收信

- **POST** `/accounts/{account_code}/start`
- **说明**：启动该账号 WebSocket 收信并写库
- **Body**：无

### 2.4 停止收信

- **POST** `/accounts/{account_code}/stop`
- **Body**：无

### 2.5 热加载凭证

- **POST** `/accounts/{account_code}/reload_credentials`
- **说明**：数据库中 cookie/密钥更新后调用；会先停再启
- **Body**：无

### 2.6 全部停止

- **POST** `/accounts/stop_all`
- **Body**：无

## 3. 发送消息

通用规则：

- `conversation_id` 与 `peer_uid` **至少一个**；有 `conversation_id` 时优先使用
- `peer_uid` 须为对方数字 uid
- 可选 `client_msg_id`：短时间内重复提交可防双发

### 3.1 发文本

- **POST** `/accounts/{account_code}/send/text`
- **Content-Type**：`application/json`
- **Body**：

```json
{
  "text": "你好",
  "peer_uid": "1234567890",
  "conversation_id": "",
  "client_msg_id": ""
}
```

- **成功 data 示例**：

```json
{
  "account_code": "my_test_acc",
  "conversation_id": "0:1:...",
  "peer_uid": "1234567890",
  "msg_type": "text",
  "status": "sent",
  "client_msg_id": ""
}
```

### 3.2 发表情

- **POST** `/accounts/{account_code}/send/emoji`
- **Body**：

```json
{
  "emoji_url": "https://example.com/emoji.png",
  "emoji_name": "",
  "peer_uid": "1234567890",
  "conversation_id": "",
  "client_msg_id": ""
}
```

- **成功 data**：同上，`msg_type` 为 `"emoji"`

### 3.3 发图片

- **POST** `/accounts/{account_code}/send/image`
- **Body**：

```json
{
  "image_path": "D:\\a.png",
  "peer_uid": "1234567890",
  "conversation_id": "",
  "client_msg_id": ""
}
```

- **说明**：`image_path` 为服务所在机器上的本地文件路径
- **成功 data**：同上，`msg_type` 为 `"image"`

## 4. 查询会话与消息

### 4.1 会话列表

- **GET** `/accounts/{account_code}/conversations?limit=50`
- **参数**：
  - `limit`：可选，默认 50，范围 1～500
- **成功 data 示例**：

```json
{
  "conversations": [
    {
      "conversation_id": "0:1:...",
      "display_name": "客户昵称",
      "avatar_url": "",
      "avatar_local_path": "",
      "conversation_short_id": "",
      "updated_at": "2026-07-24 17:00:00"
    }
  ]
}
```

### 4.2 消息列表

- **GET** `/accounts/{account_code}/conversations/{conversation_id}/messages?after_id=&limit=50`
- **参数**：
  - `conversation_id`：路径参数，会话 ID
  - `after_id`：可选，按消息 id 增量拉取
  - `limit`：可选，默认 50
- **成功 data 示例**：

```json
{
  "messages": [
    {
      "msg_id": "...",
      "direction": "outbound",
      "msg_type": "text",
      "content": "你好",
      "media_url": "",
      "created_at": "2026-07-24 17:01:00"
    }
  ]
}
```

## 5. 调用示例

### curl

```powershell
$base = "http://127.0.0.1:8765"
$ACC = "my_test_acc"
$PEER = "1234567890"

curl "$base/ping"
curl -X POST "$base/accounts/$ACC/start"
curl -X POST "$base/accounts/$ACC/send/text" `
  -H "Content-Type: application/json" `
  -d "{\"text\":\"测试\",\"peer_uid\":\"$PEER\"}"
curl "$base/accounts/$ACC/conversations"
curl -X POST "$base/accounts/$ACC/stop"
```

### Python

```python
import requests

BASE = "http://127.0.0.1:8765"
ACC = "my_test_acc"
PEER = "1234567890"

requests.post(f"{BASE}/accounts/{ACC}/start")
r = requests.post(
    f"{BASE}/accounts/{ACC}/send/text",
    json={"text": "你好", "peer_uid": PEER},
)
print(r.status_code, r.json())
```

## 6. 错误码说明

| code | 含义 |
|------|------|
| `account_required` | 缺少 account_code |
| `account_not_found` | 账号不存在或未启用 |
| `not_running` | 账号未启动（部分场景） |
| `auth_invalid` | 凭证无效/过期 |
| `peer_required` | 缺少 conversation_id 与 peer_uid |
| `text_empty` | 文本为空 |
| `emoji_invalid` | 表情参数非法 |
| `image_invalid` | 图片路径非法或不存在 |
| `send_unconfirmed` | 发送未确认/业务失败 |
| `account_mismatch` | 串号防护触发 |
| `invalid_request` | 请求格式错误 |
| `method_not_found` | 方法不存在 |
| `internal` | 内部错误 |

---

## 7. 使用注意

1. 先 `start` 再依赖实时收信；仅发送可不 start，但收信必须 start。  
2. 同一 `account_code` 不要与现网托管同时开启。  
3. 服务只监听本机，不对外网开放。  
4. 凭证来自 SQLite `im_accounts`，采集方式见 `README.md`。
