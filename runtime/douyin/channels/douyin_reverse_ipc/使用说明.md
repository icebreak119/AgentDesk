# 使用说明

本 zip 只含 `channels/douyin_reverse_ipc`。不能单独解压运行，必须放进已有完整仓库。

## 步骤

1. 解压后，把 `channels/douyin_reverse_ipc` 整个目录复制到仓库的 `channels/` 下。  
   确认仓库里已有：`channels/douyin_all_user/reverse_runtime/`。
2. 先看 `README.md`（从零启动），接口细节看 `接口说明.md`。
3. 服务默认：`http://127.0.0.1:8765`  
   浏览器调试：`http://127.0.0.1:8765/docs`

## 最短命令（仓库根目录）

```powershell
# 依赖（首次）
pip install fastapi uvicorn requests websocket-client

# 启动（凭证库路径按实际修改）
python -m channels.douyin_reverse_ipc.http_server `
  --db-path channels\douyin_all_user\reverse_runtime\_douyin_im_accounts.db `
  --host 127.0.0.1 --port 8765
```

无凭证时，见 README「准备凭证库」一节。
