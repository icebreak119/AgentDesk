作品名称：私域客服自治闭环（AgentDesk）

【问题与场景】
企业私域客服普遍面临多渠道会话分散、意图识别不准、自动回复不可验证、高风险动作缺审批、疑难案例难沉淀等问题。传统单 Bot 方案难以在真实生产约束下完成端到端闭环。

【核心方案】
AgentDesk 基于 AgentTeams 构建多 Agent 协同的私域客服自治基础设施。以抖音私信为主战场、企业微信为扩展渠道，设计值班长、会话编排、渠道接入、意图风控、执行核验五类 Agent，完成「聚合→分级→方案→执行→核验→审批→沉淀」全链路。关键能力沉淀为 SessionNormalize、IntentTriage、ReplyPlan、ChannelSend、OutcomeVerify 等可复用 Skill，并通过等价 MCP 工具契约接入渠道 Runtime。

【创新点与差异化】
1. 真实私域生产约束：多账号 profile 隔离、防串号、短文本二次校验、发送失败可定位。
2. Skill 与渠道解耦：换渠道仅换适配器，Agent 编排与核验逻辑复用。
3. 高风险动作可审计：审批闸门 + 执行证据留痕，支持回滚与复盘。

【开放/复用价值】
Skill Schema、Agent Identity 模板、渠道工具契约、核验协议可独立开源，供相似私域/客服场景复用。

【当前进展】
已完成抖音私信托管与发送核验能力，企微收发适配进行中；初赛完成方案设计与 AgentTeams 映射，复赛实现可运行 Demo。
