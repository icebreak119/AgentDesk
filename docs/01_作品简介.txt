作品名称：私域客服自治工作台（AgentDesk）

【问题与场景】
企业客服会话分散，容易重复处理，结果难验证，高风险动作缺审批，经验难复用。单一 Bot 难完成企业级闭环。

【核心方案】
以 AgentTeams Manager–Team Leader–Worker 为协同基点，接入抖音私信和企微本地 Webhook，设置 6 类 Agent，完成会话归一、去重、意图分级、方案生成、审批、退款执行/核验/回滚、客户确认和匿名案例沉淀，形成 8 个 Skill。

【创新与开放】
profile 隔离和幂等防串号；审批范围绑定高风险动作，核验通过后才通知；开放 Agent Identity、Skill Schema、工具契约和脱敏案例结构。

【当前进展】
抖音 Runtime、企业动作 HTTP 模拟器、企微 Webhook、实时演示页可独立运行；75 条测试通过。完整 RAG、官方 AgentTeams Runtime、真实 ERP/支付和生产 Task DB 规划于复赛。
