作品名称：私域客服自治工作台（AgentDesk）

【问题与场景】
企业私域客服的会话分散、回复不可验证、高风险缺审批、经验难复用，单 Bot 难以完成企业级闭环。

【核心方案】
以 AgentTeams Manager–Team Leader–Worker 分层为协同设计基点，以抖音私信和企业微信本地 Webhook 为双渠道输入，设置值班长、会话编排、渠道接入、意图风控、执行核验、案例学习六类 Agent，完成去重、分级、审批、HTTP 退款执行/核验/回滚、客户确认与案例沉淀；核心能力沉淀为 8 个可复用 Skill。

【创新点】
1. profile 隔离、防串号、短文本二次校验。
2. Skill 与渠道解耦，新增渠道仅替换适配器。
3. 审批闸门与执行证据可审计。

【开放价值】
Skill Schema、Identity 模板、MCP 契约可开源复用。

【当前进展】
抖音 Runtime（8765）可独立启动；企业动作模拟器（8770）提供订单查询、退款申请、执行回执和回滚；企微 Webhook（8771）转换为统一 SessionEvent；实时演示页（8780）跑通审批、HTTP 退款核验、通知和跨渠道去重。8 Skill 有 Schema，7 个可 CLI 验证。生产 RAG、官方运行时和 Task DB 为复赛项。
