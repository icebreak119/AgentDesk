# AgentDesk 代码仓库说明

## 1. 仓库地址

- 比赛主仓（公开）：https://github.com/icebreak119/AgentDesk
- 用途：初赛方案材料 + **可运行抖音 Channel Runtime** + **参考编排器 / Skill 注册表**

## 2. 项目定位（独立交付，不依赖第三方桌面壳）

**AgentDesk** 是面向私域客服的 **Agent Infra 独立项目**，不是某个商业桌面产品的插件。

| 层级 | 组件 | 说明 |
|---|---|---|
| **编排层（初赛参考实现）** | `orchestrator/` | DutyManager / SessionTL / 4 Workers；剧本 A/B/C + `trace.jsonl` |
| **Skill 层（初赛 v0.1）** | `skills/` | 8 Skill 注册表；除 ChannelSend 外均可 CLI |
| **渠道 Runtime（可独立验证）** | `runtime/douyin/` | IPC HTTP `8765`，中文 `/console` |
| **企业动作服务** | `enterprise_simulator/` | HTTP `8770`，订单查询、退款申请、执行回执、核验查询、回滚 |
| **企微适配器** | `runtime/wecom/` | Webhook HTTP `8771`，转换为统一 `SessionEvent` |
| **实时演示页** | `demo_runtime/` | 浏览器 HTTP `8780`，实时 Trace 与双渠道去重 |
| **量化评测** | `evaluation/` | 20 条固定样本、四条高风险分支、平均/P95 延迟 |
| **演示脚本** | `scripts/` | 一键启动/停止企业动作、企微和实时演示服务 |
| **工具契约** | `docs/contracts/` | MCP 等价 + errors/audit/idempotency + pytest |

**不纳入 AgentDesk 交付范围：**

- 任何其他项目的整壳 UI 或历史桌面宿主
- 任何无关本地服务、端口或渠道项目

## 3. 已提取的两块核心模块（抖音主渠道）

| 模块 | 本仓库路径 | AgentDesk 角色 |
|---|---|---|
| **渠道托管 / 入站** | `runtime/douyin/channels/douyin_all_user/reverse_runtime/` | ChannelIngress、profile 隔离、入站监听 |
| **渠道 Runtime / IPC** | `runtime/douyin/channels/douyin_reverse_ipc/` | ChannelSend 工具层，HTTP `8765`，中文控制台 `/console` |
| **登录采集** | `runtime/douyin/channels/douyin_reverse_ipc/login_service.py` | Web 端发起托管账号登录任务，Runtime 节点执行浏览器采集 |

在 **AgentDesk 仓库**内启动（工作目录 `runtime/douyin`）：

```powershell
cd runtime/douyin
pip install -r requirements.txt
$env:PYTHONPATH = (Get-Location).Path
python -m channels.douyin_reverse_ipc.http_server `
  --db-path channels\douyin_all_user\reverse_runtime\_douyin_im_accounts.db `
  --host 127.0.0.1 --port 8765
```

在线调试：`http://127.0.0.1:8765/console`

`docs/contracts/` 为 MCP 等价 JSON Schema，与 HTTP 接口一一对应。

## 5. 概念分层（评委易混淆点）

### AI Agents（推理与编排层）

| Agent | 职责 |
|---|---|
| DutyManager | 任务拆解、审批、升级 |
| SessionTL | 调度、上下文、状态机 |
| ChannelIngress | 渠道入站归一 |
| TriageGuard | 意图分级、风控 |
| ActVerify | 执行、核验、客户确认 |
| CaseLearning | 标签检索、匿名 CaseDigest、`case://` 复用 |

### Runtime Agent（执行层，非推理 Agent）

| 能力 | 说明 |
|---|---|
| 本机 IPC HTTP 服务 | `douyin_reverse_ipc`，默认 `8765` |
| 浏览器 / 凭证执行节点 | 登录态、send_im_message、会话拉取 |
| 职责边界 | 只负责工具执行，不做业务决策 |

### Skill（能力抽象层）

SessionNormalize / IntentTriage / ReplyPlan / BusinessAction / ChannelSend / OutcomeVerify / CustomerConfirm / CaseDigest

## 6. 可验证能力 ↔ 模块映射

| 能力 | 模块 |
|---|---|
| 抖音私信托管 / 入站 | `channels/douyin_all_user/reverse_runtime/dy_apis/douyin_recv_msg.py` + `channels/douyin_reverse_ipc/account_slots.py` |
| 消息发送 | `reverse_runtime/dy_apis/send_im_message.py` |
| 发送结果校验 | OutcomeVerify 对应日志分支（profile_id 可追踪） |
| 高风险退款动作 | `skills/business_action/v0.1/` + `orchestrator/models/business_action.py`；HTTP 企业服务执行、核验与补偿回滚，JSONL 保留为测试后端 |
| 多账号隔离 | profile_id / account_code 维度 |
| MCP 等价 API | `douyin_reverse_ipc` HTTP 路由 |
| 跨渠道聚合与去重 | `SessionEvent` 匿名客户标识 + 归一内容 + 5 分钟窗口；企微仅离线契约剧本 |
| 客户确认与案例复用 | CustomerConfirm + 匿名 JSONL CaseDigest + 标签检索；非完整 RAG |
