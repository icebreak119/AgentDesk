# AgentDesk 代码仓库说明

## 1. 仓库地址

- 比赛主仓（公开）：https://github.com/icebreak119/AgentDesk
- 用途：初赛方案材料、Agent Identity、Skill 清单、架构说明；复赛迁入可运行 Runtime 与编排代码

## 2. 项目定位（独立交付，不依赖第三方桌面壳）

**AgentDesk** 是面向私域客服的 **Agent Infra 独立项目**，不是某个商业桌面产品的插件。

| 层级 | 组件 | 说明 |
|---|---|---|
| 编排层（复赛） | AgentTeams Orchestrator | DutyManager / SessionTL / Workers 调度 |
| Skill 层 | 5 个核心 Skill | SessionNormalize … OutcomeVerify |
| **渠道 Runtime（已落地）** | 抖音 IPC + 托管链路 | 从工程中提取的两块模块，可独立启动 |
| 工具契约 | MCP 等价 HTTP API | `channel.send/query/history` |

**不纳入 AgentDesk 交付范围：**

- 任何第三方「云朵 / 私域大盘」整壳 UI（PySide6 宿主仅作历史开发环境，非比赛交付物）
- `xhs-ai-kefu`（`127.0.0.1:5173` 小红书项目）

## 3. 已提取的两块核心模块（抖音主渠道）

| 模块 | 源码路径（开发仓） | AgentDesk 角色 |
|---|---|---|
| **渠道托管 / 入站** | `channels/douyin_all_user/` | ChannelIngress、profile 隔离、入站监听 |
| **渠道 Runtime / IPC** | `channels/douyin_reverse_ipc/` | ChannelSend 工具层，HTTP `8765`，Swagger `/docs` |

二者可脱离第三方桌面壳独立运行：

```powershell
# 仓库根目录
python -m channels.douyin_reverse_ipc.http_server `
  --db-path channels\douyin_all_user\reverse_runtime\_douyin_im_accounts.db `
  --host 127.0.0.1 --port 8765
```

在线调试：`http://127.0.0.1:8765/docs`

复赛计划将上述模块迁入 AgentDesk 仓库的 `runtime/douyin/` 目录，并补齐 `contracts/` JSON Schema。

## 5. 概念分层（评委易混淆点）

### AI Agents（推理与编排层）

| Agent | 职责 |
|---|---|
| DutyManager | 任务拆解、审批、升级 |
| SessionTL | 调度、上下文、状态机 |
| ChannelIngress | 渠道入站归一 |
| TriageGuard | 意图分级、风控 |
| ActVerify | 执行、核验、证据 |

### Runtime Agent（执行层，非推理 Agent）

| 能力 | 说明 |
|---|---|
| 本机 IPC HTTP 服务 | `douyin_reverse_ipc`，默认 `8765` |
| 浏览器 / 凭证执行节点 | 登录态、send_im_message、会话拉取 |
| 职责边界 | 只负责工具执行，不做业务决策 |

### Skill（能力抽象层）

SessionNormalize / IntentTriage / ReplyPlan / ChannelSend / OutcomeVerify

## 6. 已落地能力 ↔ 模块映射
