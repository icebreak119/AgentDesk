## 4. 概念分层（评委易混淆点）

### AI Agents（推理与编排层）

| Agent | 职责 |
|---|---|
| DutyManager | 任务拆解、审批、升级 |
| SessionTL | 调度、上下文、状态机 |
| ChannelIngress | 渠道入站归一 |
| TriageGuard | 意图分级、风控 |
| ActVerify | 执行、核验、证据 |

### Runtime Agent（执行层，非推理 Agent）

| 能力 | 说明 |
|---|---|
| Windows 本地执行节点 | 浏览器托管、登录态、消息发送 |
| 抖音 Runtime | `send_im_message`、会话拉取、ticket 缓存 |
| 职责边界 | 只负责工具执行，不做业务决策 |

### Skill（能力抽象层）

SessionNormalize / IntentTriage / ReplyPlan / ChannelSend / OutcomeVerify

## 5. siyu 工程中已落地的真实能力（初赛证据来源）
