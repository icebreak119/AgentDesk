# 系统截图采集说明

## 用途

为初赛材料补充「真实工程证据」，让评委无需运行代码也能感知完成度。

## 采集来源（必须）

- **私域业务系统（siyu）** 中的抖音私信托管界面
- 或 Demo 录屏中的关键帧导出

## 禁止来源

- `http://127.0.0.1:5173`（xhs-ai-kefu / 小红书 Frost Desk）
- 任何与「抖音+企微 AgentDesk」叙事不一致的页面

## 建议截图清单

| 文件名 | 内容 | 状态 |
|---|---|---|
| `01_账号接入页.png` | 抖音账号托管/登录界面 | ✅ 已生成（yunduo.log 打码） |
| `02_会话工作台.png` | 私信会话列表与消息流 | ✅ 已生成（yunduo.log 打码） |
| `03_架构图或日志总览.png` | 架构图或 profile_id 日志 | ✅ 已生成 |
| `04_高风险审批任务.png` | 待回复 / AI 管线分流 | ✅ 已生成 |
| `05_核验失败任务.png` | 发送失败 / 核验告警日志 | ✅ 已生成 |

生成命令：`python docs/goai/build_submission_screenshots.py`（从 `yunduo.log` 提取并打码）

若桌面端「云朵私域」已打开，脚本会尝试自动截取窗口替换 01/02。

## 打码要求

- 客户昵称、手机号、conversation_id 等敏感信息请打码
- 保留 `profile_id`、分支关键字（如 `verify_failed`）以便证明工程能力
