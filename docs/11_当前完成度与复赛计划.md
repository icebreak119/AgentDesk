# AgentDesk 当前完成度与复赛计划

> 本文档用于初赛评审，明确「已完成 / 进行中 / 复赛计划」，避免过度承诺。

## 1. 总体结论

**初赛定位：重设计、重工程思路、重真实场景，不声称 AgentTeams 全栈已可运行。**

可对外表述：

> 抖音 Channel Runtime（`douyin_all_user` + `douyin_reverse_ipc`）可独立启动，消息收发与核验约束已落地；  
> AgentDesk 多 Agent 编排、Trace 工作台与 Task Runtime 后端为复赛实现项；  
> 初赛提交以方案设计、架构映射、Skill/Identity 清单与独立 Runtime 能力证明为主。

## 5. AI Agent vs Runtime Agent（完成度说明）

### AI Agents（复赛编排落地）

- DutyManager / SessionTL / ChannelIngress / TriageGuard / ActVerify
- 初赛：Identity + 协作协议 + 状态机设计 ✅
- 复赛：AgentTeams 运行时调度 🔄

### Runtime Agent（已部分落地）

- Windows 本地执行节点、浏览器托管、抖音发送执行
- 初赛：真实渠道执行能力 ✅
- 复赛：统一工具契约 + MCP 适配层 🔄

## 6. Trace 工作台说明（重要）

**初赛状态：设计目标 + 复赛实现项。**

当前不存在可对外演示的「AgentDesk Trace 工作台全链路页面」。  
如后续建设，将支持：

- 任务队列查看
- 高风险审批任务详情
- verify_failed 证据追踪

初赛材料中的 Trace 相关内容均为**架构设计**，不代表后端已全部打通。
