# AgentDesk 运行说明（初赛版）

## 1. 适用范围

本文档说明**初赛阶段**评委/开发者如何理解系统运行方式。

- **AgentDesk 仓库**：当前以设计材料为主，无强制可运行编排服务。
- **真实渠道能力**：来自私域业务系统（siyu）中的抖音/企微模块。

## 2. 初赛可验证内容

| 内容 | 是否可本地运行 | 说明 |
|---|---|---|
| 方案 PDF / 架构图 | ✅ | 直接阅读 `docs/` |
| 抖音私信收发 | ✅ | 需在私域业务系统中启动 |
| AgentTeams 编排服务 | ❌ 复赛 | 初赛为设计稿 |
| Trace 工作台全链路 | ❌ 复赛 | 初赛不声称已全打通 |

## 3. 私域系统（抖音能力）启动示意

> 以下为业务系统启动参考，具体以实际部署为准。

```powershell
# 进入私域项目目录
cd C:\Users\31368\Desktop\siyu

# 语法检查（示例）
python -m py_compile channels/douyin_all_user/dysx/app/core/bot.py

# 运行测试（示例）
python -m pytest channels/douyin_all_user/dysx/tests/test_core.py -q -p no:cacheprovider -W error::RuntimeWarning
```

桌面端入口：`main_mata.py`（PySide6 主程序）。

## 6. 已知限制（初赛诚实说明）

1. Task Runtime 后端、审批流后端、Evidence 持久化：复赛实现。
2. Trace 工作台：当前为设计目标，非已上线全功能页面。
3. 企微统一适配：进行中，初赛以抖音深做为主。
4. Demo 视频需使用公网可访问链接，不能提交 localhost。

## 7. 复赛运行目标（计划）

```bash
# 计划形态（复赛）
npm install
npm run dev:orchestrator
npm run dev:trace-web
```

届时将提供：

- `/tasks` 任务编排 API
- 审批闸门接口
- Trace 查询与证据检索
