## 4. 启动抖音 Channel Runtime（推荐 Demo 入口）

### 4.1 确认凭证库

```powershell
python -c "import sqlite3; c=sqlite3.connect(r'channels/douyin_all_user/reverse_runtime/_douyin_im_accounts.db');
print([dict(r) for r in c.execute('select account_code,enabled from im_accounts').fetchall()])"
```

若无账号，参见 `channels/douyin_reverse_ipc/README.md` 采集凭证。

### 4.2 启动 IPC HTTP 服务

```powershell
python -m channels.douyin_reverse_ipc.http_server `
  --db-path channels\douyin_all_user\reverse_runtime\_douyin_im_accounts.db `
  --host 127.0.0.1 `
  --port 8765
```

验证：

- 浏览器打开：**http://127.0.0.1:8765/console**
- 即 AgentDesk 的 **MCP 等价工具层**在线调试界面

### 4.3 语法 / 单元测试（托管模块）

```powershell
python -m py_compile channels/douyin_all_user/dysx/app/core/bot.py
python -m pytest channels/douyin_all_user/dysx/tests/test_core.py -q -p no:cacheprovider -W error::RuntimeWarning
```
