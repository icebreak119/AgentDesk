# AgentDesk 运行说明（初赛版）

## 1. 适用范围

本文档说明**初赛阶段**如何独立验证 AgentDesk 的**抖音渠道 Runtime**（不依赖第三方桌面壳）。

- **AgentDesk GitHub 仓**：含 `docs/` 初赛材料 + `runtime/douyin/` 可运行源码
- **可运行能力**：克隆后进入 `runtime/douyin` 即可启动 8765 服务

## 3. 环境准备

```powershell
cd runtime/douyin
pip install -r requirements.txt
playwright install chromium   # 仅首次采集凭证时需要
```

## 4. 启动抖音 Channel Runtime（推荐 Demo 入口）

### 4.1 确认凭证库

```powershell
cd runtime/douyin
$env:PYTHONPATH = (Get-Location).Path
python -c "import sqlite3; c=sqlite3.connect(r'channels/douyin_all_user/reverse_runtime/_douyin_im_accounts.db');
print([dict(r) for r in c.execute('select account_code,enabled from im_accounts').fetchall()])"
```

若无账号，参见 `runtime/douyin/channels/douyin_reverse_ipc/README.md` 采集凭证。

### 4.2 启动 IPC HTTP 服务

```powershell
cd runtime/douyin
$env:PYTHONPATH = (Get-Location).Path
python -m channels.douyin_reverse_ipc.http_server `
  --db-path channels\douyin_all_user\reverse_runtime\_douyin_im_accounts.db `
  --host 127.0.0.1 `
  --port 8765
```

验证：

- 浏览器打开：**http://127.0.0.1:8765/console**

### 4.2 一键启动企业动作、企微和实时演示

```powershell
cd AgentDesk
.\scripts\start_demo.ps1
Start-Process "http://127.0.0.1:8780/"
```

停止服务：

```powershell
.\scripts\stop_demo.ps1
```

也可以手动分别启动：

```powershell
cd AgentDesk
python -m enterprise_simulator.server --port 8770
python -m runtime.wecom.server --port 8771
python -m demo_runtime.server --repo-root $PWD --port 8780
```

浏览器打开：**http://127.0.0.1:8780/**，点击“启动实时演示”。

### 4.3 单独运行 HTTP 退款剧本

```powershell
python -m orchestrator.demo.script_b_approval `
  --business-action-backend http `
  --enterprise-url http://127.0.0.1:8770 `
  -o tmp\http_trace.jsonl
```
- 即 AgentDesk 的 **MCP 等价工具层**在线调试界面
- 在「托管账号登录」面板选择已有账号，或填写新账号编号后可发起采集任务；Runtime 会在本机打开浏览器完成登录并回写凭证库

### 4.3 语法 / 单元测试（托管模块）

```powershell
# 在 AgentDesk 仓库根目录执行
python -m pytest -q
python -m pytest runtime/douyin/channels/douyin_reverse_ipc/tests -q
python -m orchestrator.demo.script_c_multichannel_case

## 7. 已知限制（诚实说明）

1. 源码位于本仓库 `runtime/douyin/`，不再依赖外部开发仓路径。
2. 生产级 Task DB、审批 API、可查询 Evidence DB 与 Trace Web UI：复赛实现；初赛使用参考编排、JSONL Trace、HTTP 企业模拟器和匿名 CaseDigest 档案。
3. 企微扩展：初赛提供本地 Webhook 适配器和统一 SessionEvent；生产验签、重试和队列属于复赛。
4. Demo 视频请上传公网 URL，官网表单勿填 localhost。
5. 剧本 B 验证审批后才调用 HTTP 企业动作接口；只有退款动作核验通过才发送客户通知，核验失败触发补偿回滚；不将本地模拟器表述为真实退款或账户变更系统。

# AgentDesk 仓内（计划）

```
